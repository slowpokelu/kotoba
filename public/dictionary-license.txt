Modifications: selected four-character readings, normalized katakana to
hiragana, removed reading annotations, deduplicated readings, extracted
unambiguous spelling-to-reading mappings. The derived dictionary data is
distributed under CC BY-SA 4.0. EDRDG does not endorse this application.

The source project includes scripts/update-dictionary.mjs to rebuild this
extract from the current EDICT2 release. Run it monthly and before release.
